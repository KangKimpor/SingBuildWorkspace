# SingBuild Workspace → Figma port

Editable Figma screens generated from code (auto layout, text nodes, vector icons,
real components), not screenshots.

## Where things live

| Path | Purpose |
| --- | --- |
| `docs/figma/lib.js` | Shared helper library: design tokens, text/frame builders, ~60 lucide icons, shell components, page scaffolds. |
| `docs/figma/lib-doc.js` | Same library with its font-loading `await` replaced by `bootFonts()`, so it can be `eval`'d inside a Figma plugin run. Generated by `scripts/figma-prep.mjs`. |
| `docs/figma/lib-names.json` | Top-level identifiers in `lib-doc.js`, used to build the eval export expression. |
| `docs/figma/sNN-*.js` | One file per screen. Each file is a plain async function body. |
| `docs/screenshots/figma/` | 33 ground-truth screenshots captured from the running app. |
| `scripts/figma-serve.mjs` | Static server for `docs/figma/` on `http://127.0.0.1:8099`. |
| `scripts/figma-prep.mjs` | Regenerates `lib-doc.js` from `lib.js`. |

## Pushing screens through the Figma MCP server

The whole library is stored once in the document's shared plugin data under
`singbuild/lib`, so individual pushes only carry the screen code.

Store / refresh the library (payload ≈ 46 kB, needs `use_figma`):

```js
const lib = await fetch("http://127.0.0.1:8099/lib-doc.js").then((r) => r.text());
code = `return (async function(){
  figma.root.setSharedPluginData('singbuild','lib', ${JSON.stringify(lib)});
  return 'stored ' + figma.root.getSharedPluginData('singbuild','lib').length;
})();`;
```

Push one or more screens (payload ≈ screen size + 2 kB):

```js
const names = await fetch("http://127.0.0.1:8099/lib-names.json").then((r) => r.json());
const expr = "({" + names.map((n) => n + ":" + n).join(",") + "})";
const files = ["s02-tasks.js", "s03-search.js"];
const srcs = [];
for (const f of files) srcs.push(await fetch("http://127.0.0.1:8099/" + f).then((r) => r.text()));

const head = `return (async function(){
  var L = eval(figma.root.getSharedPluginData('singbuild','lib') + "\\n;" + ${JSON.stringify(expr)});
  ${names.map((n) => `var ${n}=L.${n};`).join("")}
  await bootFonts();
  var out = [];
`;
const body = srcs
  .map((s) => `  out.push(await (async function(){ ${s}\n })());`)
  .join("\n");
const code = head + body + "\n  return JSON.stringify(out);\n})();";
```

Notes:

- `use_figma` rejects `code` longer than 50000 characters — keep each call well under.
- Screen code runs in a strict-mode `eval`, so declarations do **not** leak into the
  caller scope; that is why the library is re-exported as an object `L` above.
- `figma.createPage()` does not switch pages — always `await figma.setCurrentPageAsync(page)`.
- `desktopScreen()` / `surfacePage()` / `widePage()` / `centerPage()` / `mobileScreen()`
  all replace a frame of the same name, so screens are idempotent and can be re-pushed.

## How to run in Figma

1. Open Figma Desktop (or Figma in the browser).
2. Open the Figma file: <https://www.figma.com/design/pCW8aVc3qrvbJki2tRn1Y5> (or any blank Figma Design file).
3. In Figma menu: **Plugins** → **Development** → **Import plugin from manifest…**
4. Select `figma-plugin/manifest.json`.
5. Run the plugin **SingBuild Workspace — screens**. It automatically generates and populates all 33 screens across `01 · Desktop screens` and `02 · Mobile screens` in seconds!

## Known constraints

- The team is on Figma **Starter** with a **View** seat. The MCP server allows only a
  handful of read tool calls per month, and `use_figma` stops working once that
  allowance is spent. Restoring the rest of the port needs a Pro seat (200 calls/day).
- Because every screen is a re-runnable function, a quota reset means re-pushing is
  simply one batch call per 5–8 screens.
